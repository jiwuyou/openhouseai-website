OpenHouse 是一个可扩展的个人设备工作平台。它用统一桌面连接小 App、本地服务、Runtime、组件市场与 AI 助手，同时把安装和维护交给 WuxianPi。

平台结构

稳定宿主，动态能力

Android 应用提供桌面、工作区与系统能力；本地 Runtime 承载服务；市场持续交付组件、插件与资源。每一层都可以独立演进。

01

桌面与小 App

将网页、原生能力和本地服务组织成可打开、可置顶的统一入口。

02

组件与服务

用清晰的注册表描述端口、健康状态、依赖和工作区入口。

03

Runtime

让可移植的应用能力在设备本地运行，并由控制面统一发现。

04

Hub 与市场

分发维修插件、运行资源和组件说明，让能力不必等待 APK 更新。

OpenHouse 生态

平台负责承载，WuxianPi 负责照看

屋

OpenHouse Workspace

用户每天打开的桌面与工作区。应用入口、服务状态和内容在这里汇合。

巫

WuxianPi 管家

OpenHouse 的维修助手和 AI 媒介，负责首次安装、更新、诊断与日常维护；它不是另一个平台。

集

OpenHouse Hub

面向用户和开发者的分发入口，承载经过版本管理的插件、资源与组件信息。

For developers

让一个服务成为桌面上的小 App

描述服务端口、健康接口、入口 URL 与 AI 能力层，注册到 OpenHouse 后即可被工作区发现。平台关注清晰契约，不要求业务采用单一技术栈。

component.json
{
  "id": "my.workspace.app",
  "title": "My App",
  "endpoint": "http://127.0.0.1:3000",
  "health": "/health",
  "ai": { "layer": "workspace" }
}
