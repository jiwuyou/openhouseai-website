openhouse ai

在手机上初始化 Ubuntu、OpenCode、Claude Code、Codex CLI 和 Reasonix， 尽量让用户不输入终端命令也能开始使用 AI 编程工具。

claude reasonix codex oc --continue

产品特点

为手机上的 AI 编程做最小可用闭环

一键初始化

引导用户完成后台运行权限、Ubuntu 环境、AI 工具安装和 DeepSeek Key 配置。

广泛模型接入

OpenCode 支持接入多种大模型 API，用户可以继续让 AI 帮自己配置更多服务。

原生网页访问

OpenCode Web 默认端口为 4096，可复制网址到浏览器使用，减少终端操作压力。

终端快捷键

底部快捷键提供 Claude、Reasonix、Codex、OpenCode 和常用参数入口。

快速开始

安装后从菜单进入 AI 软件安装引导

第一次启动会先进入 Termux 终端。点击菜单后，阅读并同意使用说明， 再进入 AI 软件安装引导。安装过程通常需要 10 到 30 分钟，建议使用 Wi-Fi。

  1. 开启忽略电池优化，保证安装过程不中断。
  2. 点击一键初始化，等待 Linux 环境和 AI 工具安装。
  3. 阅读 DeepSeek Key 说明，打开 DeepSeek 平台申请 API Key。
  4. 保存并配置 Key，安装完成后启动 OpenCode Web。

使用手册

官网手册规划

初始化安装建议阅读 终端、Ubuntu 与底部快捷键 Claude Code、Codex CLI、Reasonix 简介 OpenCode Web 使用说明

终端

Termux 是入口，Ubuntu 是 AI 工具运行环境

openhouse ai 的 AI 软件主要安装在 Ubuntu 中。底部快捷键可以帮助用户输入 exit、ubuntu、claude、reasonix、codex、oc 和 --continue 等常用内容。

底部快捷键支持自定义，也支持多页按键。用户可以让 AI 帮自己修改配置。

AI Agent

默认安装的 AI 编程软件

Claude Code

顶级 AI Agent 工具。可以输入 claude 开始，输入 claude --continue 接续对话。

OpenCode

模型接入范围广，并且原生支持 Web 页面，适合通过浏览器使用。

Reasonix

适配 DeepSeek 的 AI 编程软件，用于保证低成本可用的兜底体验。

Codex CLI

已安装。DeepSeek 暂未官方给出直接接入方式，可后续让 AI 帮忙配置。

OpenCode Web

默认从 Ubuntu 的 /root 启动

新建项目时，OpenCode Web 的项目路径建议先使用 /root。App 菜单中提供 启动、停止、重启和自定义端口启动入口。

默认地址 http://127.0.0.1:4096
